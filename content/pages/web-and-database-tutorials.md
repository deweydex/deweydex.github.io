These sites supplement [dewlab](https://deweydex.github.io/dewlab) in my classes. Each one runs in the browser, so nothing needs to be installed, and each gives a student a friendly place to begin. A teacher can take any of them as they are, or copy them and change them.

### HTML, CSS and SQL lessons

Thirteen lessons take a student from the basics of HTML, which gives a page its structure, through CSS, which styles it, and pages that work on a phone, to publishing a site with GitHub Pages. Two SQL quizzes ask questions of a database inside a story. In one the learner looks after a shop full of plushies, and in the other a school timetable gives practice with joins. [Open the lessons](https://deweydex.github.io/WADB_Tutorials) · [Code on GitHub](https://github.com/deweydex/WADB_Tutorials)

### HTML, CSS and SQL on one page

A short interactive page gives a first taste of all three languages, with examples that the reader edits and runs. It suits someone who is deciding whether web development is for them. [Open the page](https://deweydex.github.io/HTML-CSS-SQL-JS) · [Code on GitHub](https://github.com/deweydex/HTML-CSS-SQL-JS)

### Starter websites

A blank folder is a hard place to begin. The project template has five pages, Home, About, Gallery, Contact and Resources, with placeholder text and comments in the code that explain why the structure works. The portfolio template is a smaller personal site. A student copies one into their own GitHub account, replaces the text, restyles the pages and publishes the result. [Project template](https://deweydex.github.io/project_wad) · [Portfolio template](https://deweydex.github.io/portfolio_wad) · [Code for the project template](https://github.com/deweydex/project_wad) · [Code for the portfolio template](https://github.com/deweydex/portfolio_wad)

### From a click to a database

This tutorial follows one small project, a vending machine page, from the click of a button to the database and back. It explains every line of code beside the code, and it names each step: the browser, the network, a server, an API, SQL, a database, JSON and the DOM. There are two editions that build the same page, one with the server in Python and one with it in TypeScript. [Open the tutorial](https://deweydex.github.io/E2E) · [Code on GitHub](https://github.com/deweydex/E2E)
