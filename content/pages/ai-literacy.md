A large language model is a program trained on a great deal of text so that it can write and answer questions in ordinary language. Chatbots such as ChatGPT, Claude and Gemini run on large language models. Most people who use them have never been shown how they work, where they fail, or how a student might use them well. These workshops try to fill that gap, in two forms.

I wrote the materials for my own workshops with teachers, and they are drafts. I changed them after each session and I expect to change them again. Each link below opens a page in the archive of my earlier site, which is why it carries a banner saying so.

### Workshops without code

These sessions need no programming. They give a teacher the vocabulary and the habits of mind to judge what a chatbot says.

- [AI technologies](old/Teaching/prior-teaching/2025-26/ai-workshops-for-teachers/non-technical-ai-workshops-for-teachers/0-ai-technologies/) compares four ways a tool finds information: a search engine, a model with no internet, a model that reads your own documents, and a mix of those.
- [Understanding LLMs in context](old/Teaching/prior-teaching/2025-26/ai-workshops-for-teachers/non-technical-ai-workshops-for-teachers/1-understanding-llms-in-context/) explains what a large language model is and how it produces its output.
- [Tool limitations](old/Teaching/prior-teaching/2025-26/ai-workshops-for-teachers/non-technical-ai-workshops-for-teachers/2-tool-limitations/2-tool-limitations-filled/) is an exercise in doubting a chatbot with care, by working out which part of a tool produced which part of an answer.
- [LLMs and teaching](old/Teaching/prior-teaching/2025-26/ai-workshops-for-teachers/non-technical-ai-workshops-for-teachers/3-llms-and-teaching/) looks at how students use these tools, and why the conversation about detection and prohibition hides more useful questions.

### Workshops with code

These sessions build machine learning from the bottom, for teachers who want to see inside the machine. Each uses Python notebooks that run in a browser.

- [Day 1: learning a line and artificial neurons](old/Teaching/prior-teaching/2025-26/ai-workshops-for-teachers/technical-ai-workshops-for-teachers/day-1-intro-learning-a-line-and-artificial-neurons/) starts with fitting a straight line to data and moves to a single artificial neuron.
- [Day 2 and 3: from lines to neurons to networks](old/Teaching/prior-teaching/2025-26/ai-workshops-for-teachers/technical-ai-workshops-for-teachers/day-2-3-from-lines-to-neurons-to-networks/) joins neurons into small networks.
- [Day 3](old/Teaching/prior-teaching/2025-26/ai-workshops-for-teachers/technical-ai-workshops-for-teachers/day-3/) has assignments in which you build a neuron and a multi-class network yourself.
