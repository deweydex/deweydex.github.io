# deweydex.github.io

The source of https://deweydex.github.io/ . It is the same project as the GitLab one at https://gitlab.com/deweydex/jsaaron , copied by hand for now, and the two are edited separately.

- `content/` is the site. `tools/build.py` turns it into `public/`, and `.github/workflows/pages.yml` publishes that.
- Add `?edit` to a page address to edit the page in place. The editor asks for a fine-grained GitHub token for this repository with Contents: read and write.
- The site that stood here until November 2025 is on the branch `archive-2025-11`.
