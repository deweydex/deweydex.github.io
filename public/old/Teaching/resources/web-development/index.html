Web Development Resources

Web Development Resources

HTML & CSS — Reference

  • MDN — Learn HTML — Mozilla's comprehensive HTML learning path, from basics to semantic markup. The standard reference. From: Web Authoring (DCFE)

  • MDN — HTML Reference — Full HTML element reference; useful when you need to look up exactly what an element does. From: Web Authoring (DCFE)

  • MDN — HTML Basics — Short beginner-friendly introduction to HTML structure. Good first read. From: Web Authoring (DCFE)

  • MDN — CSS Basics — Companion page covering CSS selectors, properties, and how styles apply to HTML. From: Web Authoring (DCFE)

HTML & CSS — Interactive Learning

  • freeCodeCamp — Free, structured curriculum covering HTML, CSS, JavaScript, and much more. From: Web Authoring (DCFE)

  • The Odin Project — Full-stack foundations course; more demanding than freeCodeCamp, rewards persistence. Also available via freeCodeCamp. From: Web Authoring (DCFE)

  • Codecademy — HTML & CSS — Guided HTML and CSS courses including Advanced CSS; good for structured practice. From: Web Authoring (DCFE)

  • CSS Grid Garden — Game-based CSS Grid tutorial; makes grid layout click fast. From: Web Authoring (DCFE)

  • Flexbox Froggy — Game-based Flexbox tutorial; the fastest way to learn CSS flexbox. From: Web Authoring (DCFE)

Markdown

  • Markdown Guide — The definitive reference for Markdown syntax, covering basic and extended features. From: Communications

  • Markdown Tutorial — Interactive tutorial for learning Markdown by doing, recommended for complete beginners. From: Communications

  • StackEdit — Browser-based Markdown editor with a live preview; a step up from basic online editors. From: Communications

  • Markdown Online — Simple in-browser Markdown editor used in class. From: Communications

Hosting & Deployment

  • GitHub Pages — Free static site hosting via GitHub; the main option used in class. From: Web Authoring (DCFE)

  • Glitch — Browser-based code editor and hosting platform; good for projects that need a back end. From: Web Authoring (DCFE)

  • Carrd.co — Simple, free website builder used for student web pages and artist statements in class. From: Communications

Tutorial Repositories

  • AIML Tutorials Step by Step — Step-by-step web authoring tutorials created for the AIML Web Authoring class; fork or download the whole repository to use the template. From: AIML Web Authoring

  • Learn HTML, CSS, GitHub, and More — Additional tutorials covering HTML, CSS, and GitHub for students who want to go further. From: AIML Web Authoring

Going Further

  • Hugo — Fast static site generator; worth knowing once you outgrow simple website builders. From: Web Authoring (DCFE)

  • How Modern JavaScript Frameworks Work — By Building One — A clear explanation of what React and similar frameworks are actually doing under the hood. Recommended once you're comfortable with plain HTML/CSS/JS. From: Web Authoring (DCFE)

  • Learn TypeScript — Scrimba — Interactive TypeScript course; good if you're moving from JavaScript toward typed, structured code. From: Web Authoring (DCFE)

  • Learn TypeScript — Codecademy — Codecademy's TypeScript course; alternative to Scrimba. From: Web Authoring (DCFE)
