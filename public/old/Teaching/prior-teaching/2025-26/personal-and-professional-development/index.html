Week of March 2

How to request an extension.

Types of extensions: - Due to illness, death in the family, other emergency - Due to unforeseen work conflict (unlikely — due dates are usually far in advance) - Everything else is usually a question of preparedness

Key words: grace, framing, contrition, extenuating circumstances, compassionate consideration.

Example email template worked through in class: acknowledging a planning failure, attaching a draft, proposing a new date, asking for feedback rather than regrading.

Week of December 1

GitHub Pages — getting started.

Create a new repository with a README file. Use Markdown to build your personal page. Focus on content (text, links) before worrying about formatting — iterate quickly.

Content to include: 1. Name and biographical info you want to share 2. Current context — you're a student, what else is happening? 3. Goals (these will change) 4. Programming and human languages you've learned

Markdown resources: - Markdown Guide - GitHub Markdown — Basic syntax - Markdown Tutorial - StackEdit — online editor (or edit directly on GitHub)
