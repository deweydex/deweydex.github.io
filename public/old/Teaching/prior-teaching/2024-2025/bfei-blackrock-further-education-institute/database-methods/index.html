Database Methods

Database Methods

QQI Level 5 (5N0783) | Blackrock Further Education Institute | 2024–25

About This Course

Database Methods ran alongside Web Authoring as one of the two foundation modules of the year — HTML and CSS on one side, SQLite and CRUD operations on the other. Students learned to design database structures, choose appropriate data types, and write SQL to create, read, update, and delete data.

The two modules came together in the final weeks with a full-stack project: students built a web-connected database with a designed schema and working queries, with Web Authoring assessing the front end and Database Methods assessing the back end. The same project generated evidence for both modules, so students produced one coherent piece of work rather than two disconnected assignments.

Database skills also fed into the wider AI/ML course work — students used the SQL from this module alongside Pandas and Jupyter notebooks in their data analysis for Computational Methods and Mathematics for IT.

Learning Outcomes

  • LO1 — Create database structures with appropriate data types
  • LO2 — Insert, update, and delete data
  • LO3 — Write queries to retrieve and filter data
  • LO4 — Apply SQL data types appropriately
  • LO5 — Demonstrate proficiency with CREATE, INSERT, SELECT, and DELETE syntax

Assessment

  • SQL quizzes throughout the module
  • Project: a web-connected database with schema design and working queries (shared evidence with Web Authoring)
