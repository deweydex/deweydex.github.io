2024–25 Teaching Archive

Teaching from the 2024–25 academic year across two institutions.

Dublin College Dundrum / DCFE (2024–25)

Four courses at QQI Level 5:

  • Foundations of AI for Business — Exploring AI/ML tools critically, building media literacy and practical fluency
  • Maths for IT — QQI Level 5 mathematics taught in close connection with programming, month by month through the year
  • Web Authoring — Fundamentals of web development for IT students
  • Programming Design Principles — Python programming with an emphasis on structured thinking and collaborative problem-solving

Dublin College Blackrock / BFEI (2024–25)

AI and Machine Learning Foundations course at QQI Level 5–6. Three core courses, taught as an integrated programme with three deliberate cross-module integration points.

  • Foundations of Object Oriented Programming (FOOP) — C# OOP taught through a three-part solar system project
  • Mathematics for IT — Taught in close connection with programming and machine learning
  • Database Methods — Relational databases and SQL, integrated with Python and data analysis
  • Cross-Module Integration Summary — How the modules were connected through shared projects and assessment
